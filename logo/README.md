# 新宮町商工会のロゴ（商工会章）

歯車の中にS。全国共通の商工会章で、新宮町商工会の現行サイトでも使われているもの。

## 出どころ

現行サイトのサイトアイコン `shokokai-icon.jpg`（200×196・JPEG）
http://www.shinguumachi.or.jp/wordpress/wp-content/uploads/2022/03/shokokai-icon.jpg

想像で描き起こしたものではなく、**この画像をそのまま整えたもの**。
元画像とドット単位で比較して形は100%一致している（33,856px中ズレ0px）。
やったのは「白背景を透明にする」「JPEGのギザギザを整える」「拡大」だけ。

## ファイル

| ファイル | 用途 |
|---|---|
| shokokai-mark-1024.png | 印刷・大きく使うとき |
| shokokai-mark-512.png | 基本。ここから縮小して使う |
| shokokai-mark-256.png | |
| shokokai-mark-128.png | サイトのヘッダー用 |
| shokokai-mark-white-512.png | 濃い背景（フッターなど）に載せる白版 |

インクの色: RGB(33, 40, 48) ＝ #212830

## 注意

- 元が200px程度のJPEGなので、**これ以上の情報は無い**。1024版は拡大しただけで、細部が増えているわけではない。
- 歯車の歯が細かいため、**32px以下だと歯がつぶれて団子に見える**。ファビコンなど小さく使う場合は、歯車を省いてSだけにするなど、小サイズ専用の形を別に作ったほうがよい。
- きれいな大きいデータ（ai / eps / svg / 高解像度png）を商工会が持っている可能性が高い。**本番前に必ず原本をもらうこと。**
