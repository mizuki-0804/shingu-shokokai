## 現行サイトのマークとの照合結果

現行サイト（ http://www.shinguumachi.or.jp/ ）のアイコン画像と重ねて比較した。

- **同じ紋章**。歯車の歯の数・歯の形・歯間の三日月の切り欠き・Sの構え、すべて一致。
- 形の一致率は85%。差の内訳は、①全体的に線の太さがわずかに違う（現行サイト版のほうが太い）②**Sの下の払いの形が少し違う**（支給版のほうが下に大きく広がる）。
- 現行サイトの画像を取り込むしきい値を60〜160まで振っても一致率は84.6〜85.2%で変わらなかったため、**取り込み方の誤差ではなく、描き方が実際に違う**。同じ紋章の別バージョンと考えられる。

**⚠️ 本番前に商工会へ確認すること:** どちらの描き方が正なのか、こちらでは判断できない。
あわせて原本（ai / eps / svg）があればもらう。
